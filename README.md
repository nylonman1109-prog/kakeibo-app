# やさしい家計簿

「毎回の入力が面倒で続かない」を解きにいく家計簿アプリ。
**レシートを撮る／一言しゃべる、で終わる**を最優先に設計しています。

公開URL: https://nylonman1109-prog.github.io/kakeibo-app/

## 機能

- **ホーム** … 今月の合計・先月との比較・分類ごとの内訳
  - 予算を決めると **今月の残り／1日あたり使える額／月末の着地見込み** が出る
- **かんたん入力**（＋ボタン）
  - 🎤 音声 … 「ラーメン 980円」と話すだけ。金額と分類を自動で推測
  - 📷 レシート … 撮影すると AI が合計金額・店名・日付・分類を読み取る
  - ✏️ 手入力 … 品名・金額・分類・日付を直接入力（過去の日付も可）
  - どの方法でも、追加前の確認画面で内容を直せる
- **履歴** … 月ごとの明細。タップで**編集・削除**。外食は「一人／複数」を記録
- **分析**
  - 今月 vs 先月の分類別比較
  - 直近6ヶ月の推移・月平均
  - シミュレーション（外食などの回数を減らすと年間いくら浮くか）
  - 集計をワンタップでコピーして ChatGPT / Claude に相談
- **設定** … 月予算・分類別予算・CSV書き出し／復元・使い方ページ

## 音声入力について

端末に合わせて3段構えで動きます。

| 端末 | エンジン |
|---|---|
| iPhone / iPad | Apple の音声認識（Siri・キーボード音声と同じ） |
| Android | Google の音声認識 |
| 上記が使えない場合 | OS標準キーボードの🎤（ディクテーション）へ誘導 |

呼び出し口は Web Speech API 共通ですが、端末ごとのクセ（iOSの結果重複・終了イベント未発火など）に合わせて設定と保険タイマーを出し分けています。一度失敗した端末は記憶して、次回から確実な方式で開きます。

> **⚠ iPhone の制限**
> ① Safari 以外のブラウザ（Chrome など）、② ホーム画面に追加したアイコンからの起動 ——
> このどちらかだと Apple 側の制限でアプリのマイクが使えません。
> **音声を使うなら Safari で開いてください。** アプリ側で自動検知し、その場合はキーボードの🎤方式に切り替えて案内します。

## レシート読み取りの仕組み

```
スマホ（撮影・長辺1280pxに縮小）
   ↓ 画像を直接送る（APIキーは利用者の端末内）
Gemini（gemini-flash-latest）で 店名・合計・日付・分類 を抽出
   ↓
アプリの確認画面に反映（その場で直せる）
```

- **APIキーは利用者が ⚙️設定 →「レシート読み取りの設定」から貼り付けます。** コードには書きません
- キーの持ち主＝使う人なので、読み取りの利用分はその人の無料枠から引かれます
- 写真はどこにも保存しません（読み取りのその場かぎり）
- 準備の手順は `docs/レシート読み取りの準備.md`。同じ内容は設定画面にも載せてあります
- 未設定のあいだは「まだ設定が済んでいません」と出て、設定画面と手入力へ誘導します
- AIの応答はそのまま信じず、分類は決まった6種、日付は形式、店名は40字で検査してから反映します

### 費目の自動仕分け

**1枚のレシートを1つの費目にまとめません。** 商品を1行ずつ読み、費目ごとに分けて記録します。

```
スーパーのレシート ¥2,160
  ├ 🍚 食費   ¥1,057 … 牛乳、食パン、豚こま肉、キャベツ
  └ 🧴 日用品 ¥1,103 … 洗濯洗剤、ティッシュ、トイレットペーパー
```

「食費と日用品が分かれない」ことが、お客さんが前の家計簿をやめた理由だったため、ここを最優先で作り込んでいます。

- プロンプトに**費目ごとの具体例と「迷ったときの原則」**（口に入るなら food／使ってなくなるなら daily）を明記
- 「店の種類で決めつけない」を明示（ドラッグストアの牛乳は food、スーパーの洗剤は daily）
- 小計・値引き・ポイント・消費税の行は商品として拾わない
- 明細の合計はレシート合計と一致しないのがふつう（税抜表示・値引き）。
  **割合を保ったまま合計に合わせ、端数は大きい行から1円ずつ配って誤差ゼロにします**
- 明細が1行も読めなかったときは、従来どおり店名から推測して1件にまとめます
- 確認画面で費目・金額を行ごとに変更でき、同じ費目にした行は1件にまとまります

> **2026-08-17 に方式を変更。** それまでは GAS で中継サーバーを立て、キーをサーバー側に隠していました。
> 準備が6手順・20分かかり、渡す相手ごとにURLと合言葉を配る必要があったため、「キーを貼るだけ」に切り替えています。
> 旧方式一式は `archive/家計簿アプリ_GAS中継_2026-08-17/`（このリポジトリの外）に退避。

## データの保存先

記録は**利用者の端末内（localStorage）にのみ保存**されます。サーバーには送信されず、開発者側からも中身は見えません。
※音声認識のときは音声が各社（Apple / Google）のエンジンを、レシート読み取りのときは画像が Google（Gemini）を経由します。

**裏返すと、機種変更やブラウザの履歴削除で記録は消えます。** 設定の「CSVに書き出す」で控えを取り、「CSVから復元する」で戻せます。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（単一HTML・ビルド不要） |
| `docs/レシート読み取りの準備.md` | APIキーの取り方・貼り方（2手順） |
| `mic-check.html` | マイク診断ページ（音声が動かない端末の原因切り分け用） |
| `engine-test.html` | 音声エンジン比較（ブラウザ標準 / Whisper内蔵 / Gemini の実測） |

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要の単一HTMLです。

初回は**お試し用のサンプル記録**が入っています。自分の記録を始めるときは、ホーム上部の「サンプルを消して始める」から一括で消してください。
