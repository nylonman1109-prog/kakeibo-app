# やさしい家計簿

「毎回の入力が面倒で続かない」を解きにいく家計簿アプリ。
**レシートを撮る／一言しゃべる、で終わる**を最優先に設計しています。

## 機能（第1弾）

- **ホーム** … 今月の合計・分類ごとの内訳・先月との比較
- **かんたん入力**（＋ボタン）
  - 🎤 音声 … 「消しゴム 100円」と話すだけ。金額と分類を自動で推測
  - 📷 レシート … 撮影して合計金額を読み取り、分類を推測（確認画面で修正可）
  - ✏️ 手入力 … 品名・金額・分類を直接入力
- **履歴** … 月ごとの明細。外食は「一人／複数」を記録
- **分析**
  - 今月 vs 先月の分類別比較
  - 直近6ヶ月の推移・月平均
  - シミュレーション（外食の回数と単価から年間見込み・節約余地を試算）
  - 集計をワンタップでコピーして ChatGPT / Claude に相談

## 音声入力について

端末に合わせて3段構えで動きます。

| 端末 | エンジン |
|---|---|
| iPhone / iPad | Apple の音声認識（Siri・キーボード音声と同じ） |
| Android | Google の音声認識 |
| 上記が使えない場合 | OS標準キーボードの🎤（ディクテーション）へ誘導 |

呼び出し口は Web Speech API 共通ですが、端末ごとのクセ（iOSの結果重複・終了イベント未発火など）に合わせて設定と保険タイマーを出し分けています。

## データの保存先

記録は**利用者の端末内（localStorage）にのみ保存**されます。サーバーには送信されず、開発者側からも中身は見えません。
※音声認識の処理時のみ、音声が各社（Apple / Google）のエンジンを経由します。

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要の単一HTMLです。
スマホのホーム画面に追加すると、アプリのように使えます。
