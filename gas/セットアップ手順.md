# レシート読み取りサーバーの立て方

やることは4つ。**全部あわせて15〜20分**です。ここが終わればレシート撮影が本当に動きます。

---

## なぜサーバーが要るのか

レシートを読むのは Google の AI（Gemini）です。これを呼ぶには **APIキー**（合言葉）が要ります。
このキーを `index.html` に直接書くと、GitHubで公開しているので**誰でも見えて、誰でも使えて、請求だけこちらに来ます。**

そこで、キーは Google Apps Script（GAS）側に隠し、アプリからは「写真を送って結果をもらうだけ」にします。

```
スマホ ──写真──▶ GAS（キーはここ） ──▶ Gemini ──▶ 読み取り結果 ──▶ スマホ
```

---

## 手順1. Gemini の APIキーを取る（5分）

1. https://aistudio.google.com/apikey を開く（Googleアカウントでログイン）
2. **「APIキーを作成」** を押す
3. 出てきた文字列（`AIza...` で始まる）をコピーしておく

> 💡 無料枠があります。レシート1枚あたりの消費はごくわずかで、個人利用なら通常は無料枠に収まります。
> 課金が心配なら、Google Cloud 側で予算アラートをかけておくと安心です。

---

## 手順2. GAS のプロジェクトを作る（5分）

1. https://script.google.com/home を開く → **「新しいプロジェクト」**
2. 左上のプロジェクト名を **「やさしい家計簿 レシート読み取り」** に変更
3. エディタに出ている `function myFunction() {}` を**全部消して**、
   `gas/コード.gs` の中身を**まるごと貼り付け**る
4. 💾 で保存

---

## 手順3. APIキーを登録する（2分）

1. 左の ⚙️ **「プロジェクトの設定」** を開く
2. いちばん下 **「スクリプト プロパティ」** → **「スクリプト プロパティを追加」**
3. 次のとおり入れて保存

   | 項目 | 入れるもの |
   |---|---|
   | プロパティ | `GEMINI_API_KEY` |
   | 値 | 手順1でコピーしたキー |

> ⚠️ このキーは人に見せない・スクショに写さない。もし漏れたら手順1の画面で削除して作り直す。

---

## 手順4. ウェブアプリとして公開する（5分）

1. 右上 **「デプロイ」** → **「新しいデプロイ」**
2. 歯車 ⚙️ → 種類を **「ウェブアプリ」** に
3. 設定を次のとおりに

   | 項目 | 選ぶもの |
   |---|---|
   | 説明 | レシート読み取り v1 |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

4. **「デプロイ」** → 初回は権限の確認が出る
   → 「アクセスを承認」→ 自分のアカウントを選ぶ
   → 「このアプリは確認されていません」と出たら **「詳細」→「（プロジェクト名）に移動」** → 「許可」
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー

> 「アクセスできるユーザー：全員」は、**URLを知っている人だけがアクセスできる**という意味です。
> URLは推測できない長い文字列で、アプリの中にしか書きません。

---

## 手順5. アプリにURLを貼る（1分）

`index.html` の上のほう、`===== レシート読み取り =====` のところ：

```js
const OCR_URL = '';   // ← ここに貼る
```

↓

```js
const OCR_URL = 'https://script.google.com/macros/s/……/exec';
```

保存して push すれば完了です。

---

## 動いているか確かめる

**① サーバー単体**
コピーしたURLをブラウザでそのまま開く →
`やさしい家計簿 レシート読み取り中継：稼働中` と出れば生きています。

**② アプリから**
アプリの ＋ → 📷レシート → 手元のレシートを撮る →
5秒ほどで店名・合計・日付が入った確認画面が出れば成功。

---

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 「準備中です」と出る | `OCR_URL` が空のまま。手順5 |
| 「サーバーの設定が未完了です」 | スクリプトプロパティの名前が `GEMINI_API_KEY` になっているか。手順3 |
| 「サーバーが応答しませんでした（401/403）」 | デプロイの「アクセスできるユーザー」が**全員**になっているか。手順4 |
| 「読み取りサービスに接続できませんでした」 | APIキーが正しいか。GASの「実行数」画面のログに理由が残っています |
| 合計がズレる | レシート全体が入るように、明るい場所で撮り直す。金額は確認画面で直せます |

## コードを直したときの注意

**保存しただけでは公開版は変わりません。**
「デプロイを管理」→ 対象の ✏️ → バージョン **「新バージョン」** → 「デプロイ」で更新してください（URLは変わりません）。
