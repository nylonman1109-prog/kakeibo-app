# やさしい家計簿 使い方ガイド

## この家計簿がめざしたこと

家計簿が続かない理由は、だいたいいつも同じです。**入力が面倒。**

レシートを財布に溜めて、週末にまとめて打とうとして、そのまま挫折する。
だからこのアプリは、機能を増やすより先に**「入れるのが一瞬で終わること」**に全部を寄せました。

入れ方は3つ。どれも数秒で終わります。

- 🎤 **しゃべる** … 「ラーメン 980円」と言うだけ
- 📷 **撮る** … レシートを撮るだけ。AIが金額を読み取ります
- ✏️ **打つ** … 品名と金額を直接

そして、記録が貯まると「今月あといくら使えるか」「外食を3回減らしたら年間いくら浮くか」が自動で出ます。
**入れるのが楽 → 続く → 数字が見える → 減らせる。** この順番を狙っています。

---

## 使いはじめる前に（最初の1回だけ）

### 1. サンプルを消す

最初に開くと、**お試し用の架空の記録**が入っています。使い心地を試すためのものです。

ホームのいちばん上に出ている **「サンプルを消して始める」** を押すと、まっさらになります。
自分の記録を始める前に、必ず一度押してください。

### 2. ひと月の予算を決める（任意ですが、おすすめ）

下の **⚙️設定** → 「今月の予算」に金額を入れて保存。

これを入れると、ホームに次のものが出るようになります。

- **今月あといくら使えるか**（残額）
- **1日あたりいくらまでか**（残りの日数で割った額）
- **このペースだと月末いくらになるか**（着地の見込み）

「外食だけ15,000円まで」のように分類ごとの上限も決められます。空欄なら管理しません。

## 記録する（右下の ＋ ボタン）

### 🎤 音声でいれる

1. マイクのボタンを押す
2. 「**ラーメン 980円**」のように話す
3. **もう一度マイクを押して終了**
4. 内容を確認して「この内容で追加」

品名・金額・分類を自動で判定します。
たとえば「ラーメン」なら外食、「洗剤」なら日用品、「ガソリン」なら交通、といった具合です。

> **うまく聞き取らせるコツ**
> - 金額のあとに「**円**」を付ける（「430円」）。これがいちばん効きます
> - 「コンビニ2個で430円」のように数字が2つ出ても、円の付いた方を金額として拾います
> - 静かな場所のほうが正確です

### 📷 レシートを撮っていれる

1. 「レシート」タブ → 「タップして撮影」
2. レシート全体が入るように撮る
3. 5秒ほどで、**お店の名前・合計金額・日付・分類**が入った確認画面が出ます
4. 内容を見て「この内容で追加」

読み取りがズレていたら、**その場で直せます**（金額も日付も分類も）。

> **きれいに読ませるコツ**
> - 明るい場所で、影が入らないように
> - レシートを平らにのばして、はみ出さないように撮る
> - 長いレシートは、合計金額の部分がはっきり写っていれば大丈夫です

### ✏️ 手で打っていれる

品名・金額・分類を入れて「追加する」。

**日付を変えれば、昨日以前の買い物も入れられます。**
レシートが溜まってしまった時や、現金払いを思い出した時に使ってください。

---

## 直す・消す

**履歴** の記録を**タップすると編集画面が開きます。**

- 品名・金額・日付・分類、どれも直せます
- 消したいときは、同じ画面の下にある「この記録を削除」

金額を打ち間違えても、入れ直す必要はありません。

---

## 見る

### 🏠 ホーム

- 今月の合計と、先月と比べて増えたか減ったか
- 予算を決めていれば、残りと1日あたりの上限
- 分類ごとの内訳（多い順のバー）

### 📊 分析

3つのタブがあります。

**「月の比較」** … 今月と先月を分類ごとに並べます。増えた分類が赤、減った分類が緑。
「今月は外食が+8,000円か」と、増えた原因がすぐ分かります。

**「年間」** … 直近6ヶ月の棒グラフと月平均。ひと月の波が見えます。

**「シミュ」** … ここが面白いところです。
つまみを動かして「**外食を3回減らしたら？**」を試すと、
浮く金額・1年ぶんに換算した額・その額で何が買えるかが出ます。

> 「外食を月3回減らすと年間58,800円 → 国内旅行1回分」
> ——こういう見え方をすると、我慢が目的ではなくなります。

### 🤖 AIに相談する

分析の下にある「**今月の家計をコピー**」を押すと、集計文がコピーされます。
それを ChatGPT や Claude に貼れば、そのまま節約の相談ができます。

## 大事なこと（ここだけは読んでください）

### 🔒 記録は、あなたのスマホの中だけにあります

どこのサーバーにも送られません。**作った側からも中身は見えません。**
家計は人に見られたくないものなので、そういう作りにしています。

※音声を使うときは音声がApple/Googleの認識エンジンを、レシートを撮るときは画像がGoogleのAIを一瞬だけ通ります。写真そのものはどこにも保存されません。

### 💾 裏返すと、消えることがあります

スマホの中だけにあるということは、こういう時に消えます。

- 機種変更したとき
- ブラウザの履歴・データを消したとき

そこで **⚙️設定 → 「CSVに書き出す」** を用意しています。
月に一度でも書き出してメールなどに送っておけば、
新しい端末で **「CSVから復元する」** を押すだけで全部戻ります。

### 📱 iPhoneをお使いの方へ

Apple側の制限で、**次の開き方だとアプリのマイクが使えません。**

- Safari 以外のブラウザ（Chromeなど）で開いた時
- ホーム画面に追加したアイコンから開いた時

**音声を使う日は Safari で開いてください。**
なお、上の開き方をした場合でもアプリが自動で気づいて、
**キーボードの🎤（OS標準の音声入力）**に切り替えて案内します。声で入れること自体はできます。

## 困ったときは

| こんなとき | どうするか |
|---|---|
| 音声が反応しない | Safariで開き直す。それでもダメなら「うまく動かないときはこちら⌨️」からキーボードの🎤で |
| 聞き取りがおかしい | 金額のあとに「円」を付けて言い直す。確認画面でも直せます |
| レシートの金額がズレた | 確認画面でその場で直す。明るい場所で撮り直すと精度が上がります |
| 分類がちがう | 確認画面や編集画面で、正しい分類を押すだけ |
| 記録が消えた | 設定の「CSVから復元する」で、控えのファイルを選ぶ |
| 使い方を忘れた | ⚙️設定 → 「使い方を見る」にも同じ説明が入っています |

---

## ひとこと

最初の1ヶ月は、**完璧に入れようとしないでください。**
入れ忘れた日があってもいいし、金額がだいたいでも構いません。

3ヶ月ぶん貯まると、「分析」の数字が急に面白くなります。そこまでは気楽に。
